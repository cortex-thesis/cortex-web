81.72% is the mixed demonstration evaluation, not a measured live-EEG accuracy. The original EEG subset scores 42.11%. This artifact is selected for experimental system use; its selection does not establish biological or clinical validation.

Dataset and evaluation

The frozen dataset contains 95 original EEG rows, 300 EEG-derived augmented rows, and 1,000 artificial demonstration rows constructed around four separated coordinate centers. The latter have assigned class names and no EEG parent. The split is 1,116 training rows and 279 test rows. Augmented descendants stay with their original parents. Recordings and participants overlap between partitions, so this is not an independent-cohort evaluation.

Training and live input

K-means uses four clusters, 20 initializations and seed 2026. Artificial training class assignments name the clusters. The Random Forest learns numeric cluster IDs with 200 trees, maximum depth 6, minimum leaf size 4 and seed 2026. Test data does not fit the scaler, cluster centers, mapping, or forest.

Live input is the existing five-value EEG feature vector. The first four log10 band powers are normalized using a scaler fitted only on the 76 original training rows. TBR is accepted for interface compatibility but is not used by this model. The forest predicts a cluster, then the frozen mapping returns distracted, focused, overstimulated, or relaxed. Personal clusters do not replace this frozen classifier after additional windows.

Provenance

Data augmentation and artificial demonstration construction are distinct sources, retained in the dataset and per-source results. Supporting literature does not turn the mixed demonstration result into measured accuracy on new learners. Runtime artifact and dataset hashes are recorded in metrics.json.
