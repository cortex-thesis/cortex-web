11. Interpretation and reproducibility

  • All 1,300 augmented rows inherit labels from their source epoch. Label preservation under jitter is an assumption, not verified physiology.
  • The test rows represent only 19 independent source epochs. Do not treat 279 correlated test rows as 279 independent observations.
  • Clustering plots and EDA do not tune the classifier or modify the fixed split.
  • Do not use test results to repeatedly choose augmentation strength or model parameters and then report the same test as independent validation.
  • Seeds: split/training 2026; test augmentation 2027. Gaussian jitter SD: 0.03 log10-power units.
  • Gamma currently spans 30–45 Hz in the raw extractor; alignment with the paper’s 30–40 Hz definition is still required.
